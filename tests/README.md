# 回归测试说明

本目录包含 `close` 命令的回归测试（`test_close.py`），仅使用 Python 3 标准库。

## 运行

在项目根目录执行：

```bash
python -m unittest discover -s tests
```

全部通过时命令退出码为 0；任何用例失败时退出码非零，并输出失败用例名称与差异详情。

## 覆盖范围

- 正常结案：退出码 0、标准错误为空、标准输出为与 `show` 同结构的 JSON 对象，仅 `status` 变为 `closed`；结案后 `show` 可读到已保存的 `closed` 状态，另一条工单不受影响。
- 幂等结案：重复 `close` 同一编号仍成功、返回同一工单、工单数量不变。
- 编号格式错误：`close abc` / `close 0` / `close -1` → 退出码 1，标准错误为“工单编号必须为正整数”。
- 编号不存在：`close 999` → 退出码 1，标准错误为“工单不存在”。
- 用法错误：缺少编号或追加未知参数 → 退出码 2，标准错误包含用法提示。

每个用例在独立临时数据库中准备两条合成工单（标题“登录失败”“打印异常”），
通过 `--db` 指向临时文件，结束后自动清理，不读取或改动用户已有数据库。
