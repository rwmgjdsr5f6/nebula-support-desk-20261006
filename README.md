# 本地客服工单中心

管理客户工单的本地单机命令行工具，采用 Python 3 标准库与 SQLite，无需安装第三方依赖，也不提供任何联网功能。

当前版本支持最小流程：**创建工单**、**按编号查看工单**与**按编号结案**（暂不支持分派、回复）。

## 环境要求

- Python 3（仅使用标准库）

## 用法

入口为项目根目录下的 `main.py`：

```bash
python main.py [--db 数据库文件] <命令> [参数]
```

### 数据库位置

- 全局选项 `--db` 指定 SQLite 数据库文件路径，例如 `--db demo.sqlite`。
- 未提供 `--db` 时，默认使用**当前工作目录**下的 `tickets.sqlite`。
- 数据库文件尚不存在时会自动创建（要求其父目录已存在且可读写）；已存在则继续使用，重新运行或再次创建工单都不会清空已有记录。
- 不同 `--db` 文件中的数据彼此独立。

### 创建工单

```bash
python main.py --db demo.sqlite create --title "登录失败" --description "重置密码后仍无法登录"
```

- `--title`：工单标题。去除首尾空白后为空则拒绝创建；有效标题去除首尾空白后保存。
- `--description`：工单描述，按原文保存，允许空字符串。
- 创建成功后，工单获得该数据库中唯一的正整数编号（新数据库首条编号为 1，编号在重新运行后保持稳定），初始状态固定为 `open`。
- 成功时退出码为 0，标准输出只包含一个 JSON 对象，字段为 `id`、`title`、`description`、`status`（`id` 为整数，其余为字符串），中文可直接阅读：

```json
{"id": 1, "title": "登录失败", "description": "重置密码后仍无法登录", "status": "open"}
```

### 查看工单

```bash
python main.py --db demo.sqlite show 1
```

- `show` 后接工单编号，返回对应工单，不改变任何数据。
- 成功时退出码为 0，标准输出为包含 `id`、`title`、`description`、`status` 四个字段的 JSON 对象，内容与创建时一致。

### 结案工单

```bash
python main.py --db demo.sqlite close 1
```

- `close` 后接工单编号，仅将该工单状态由 `open` 改为 `closed`，编号、标题和描述保持原值，其他工单不受影响。
- 对已经是 `closed` 的工单再次结案同样成功，返回相同工单及 `closed` 状态，不新增记录或改变编号。
- 成功时退出码为 0，标准输出只包含一个 JSON 对象，字段与类型和查看工单一致，中文可直接阅读：

```json
{"id": 1, "title": "登录失败", "description": "重置密码后仍无法登录", "status": "closed"}
```

## 错误结果

以下情况退出码均为 1，且标准输出为空，错误信息输出到标准错误：

| 情况 | 标准错误输出 |
| --- | --- |
| 创建时标题去除首尾空白后为空 | `标题不能为空` |
| `show` 的编号不是正整数（如 `abc`、`0`、`-1`） | `工单编号必须为正整数` |
| 编号为正整数但工单不存在（如 `show 999`） | `工单不存在` |
| `close` 的编号不是正整数（如 `abc`、`0`、`-1`） | `工单编号必须为正整数` |
| 编号为正整数但工单不存在（如 `close 999`） | `工单不存在` |
| `reopen` 的编号不是正整数（如 `abc`、`0`、`-1`） | `工单编号必须为正整数` |
| 编号为正整数但工单不存在（如 `reopen 999`） | `工单不存在` |

空白标题被拒绝、编号校验失败或工单不存在时，均不会改变库中已有工单的数据（不存在的数据库按既有规则自动创建，但不会生成占位工单）。`close` 缺少编号或带有未识别参数时，退出码为 2，标准输出为空，标准错误给出用法提示。

编号按 Python `int()` 规则解析（允许正号、前导零与首尾空白）。对于能解析为正整数、但大于 SQLite 可保存的最大整数 9223372036854775807 的编号（如 `9223372036854775808`，带正号、前导零或空白的写法同理），`show`、`close`、`reopen` 一律按工单不存在处理：退出码 1，标准输出为空，标准错误仅输出 `工单不存在` 及换行，不创建占位工单、不改动已有工单。最大整数本身是合法编号，库中无对应记录时同样返回 `工单不存在`。
